arca — arte ASCII
=================
Todas as variantes abaixo são monoespaçadas. Copie exatamente, sem
reindentar. Largura máxima: 32 colunas (cabe em terminais de 40+).

6. CORES ANSI
-------------
Mesma paleta do SVG, em truecolor com degradação para 256 cores:

  casco / prompt   #56D364   \033[38;2;86;211;100m    \033[92m
  telhado          #3FB950   \033[38;2;63;185;80m     \033[32m
  água             #58A6FF   \033[38;2;88;166;255m    \033[94m
  fechadura        #E3B341   \033[38;2;227;179;65m    \033[93m
  texto            #E6EDF3   \033[38;2;230;237;243m   \033[97m
  reset                      \033[0m

Sempre verifique NO_COLOR e se stdout é um TTY antes de emitir escapes.


7. SNIPPET BASH
---------------

    print_banner() {
      [ -n "$NO_COLOR" ] || [ ! -t 1 ] && c() { :; } || c() { printf '%b' "$1"; }
      local G='\033[38;2;86;211;100m' B='\033[38;2;88;166;255m'
      local Y='\033[38;2;227;179;65m' W='\033[38;2;230;237;243m' R='\033[0m'
      printf "%b" "$G"
      cat <<'ARK'
            ________
           /        \
          /__________\
          |  ______  |
          |  | () |  |
    ______|__|____|__|______
    \                      /
     \____________________/
ARK
      printf "%b   ~~~~~~~~~~~~~~~~~~~~~~~~~~%b\n" "$B" "$R"
    }
